# evalhive-harness

Python 3.12 SDK for external EvalHive harness connector processes. Install this
package in the connector's image; it has no backend, Docker or LLM dependencies.
The wheel includes the canonical protocol 1.0 JSON Schema.

See [the SDK contract and examples](https://github.com/Atmostone/EvalHive/tree/master/sdk)
for the process protocol, lifecycle, validation and cross-language conformance.
